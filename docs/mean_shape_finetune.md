# MEANSHAPE_68 三维偏移标定与更新方法

本文档描述人脸 68 关键点 3D 模型（MEANSHAPE_68）的偏移标定方法：偏移如何计算、
如何合成进模型表、以及完整的更新与验证流程。规范实现为
[tools/pfld68_convert/finetune_offsets.py](../tools/pfld68_convert/finetune_offsets.py)。

当前标准方法为 **`--xy-fixed` 两阶段在线标定**（2026-09-09 定案，见 3.1）：
正视启动帧固定位姿一次定型全部 XY 偏移，后续帧仅微调 Z 深度与尺度。

## 1. 模型合成结构

模型表定义在 [src/pipeline/postprocess/solve_pnp.cpp](../src/pipeline/postprocess/solve_pnp.cpp)，
分三层，程序加载时静态初始化合成一次：

```
kMeanShape68[68][3]            基础表（MP468 重标定版，通用模型，不动）
  + kMeanShape68FineTuneX[68]  X 偏移块（水平形状，一维向量）
  + kMeanShape68FineTuneY[68]  Y 偏移块（垂直位置，一维向量）
  + kMeanShape68FineTuneZ[68]  Z 偏移块（深度剖面，一维向量）
  = kMShape68.v[68][3]         合成表（唯一生效模型）
```

规则：

- 基础表由 `tools/pfld68_convert/gen_mean_shape68.py --write-c` 生成/重写；
- 三个偏移块各为 68 元素一维向量，按轴独立累加，便于分轴启用/回退；
- **所有消费方（PnP、投影、眼心）只读合成表 `kMShape68.v`**，禁止单独读基础表，
  外眼距等派生量也必须取自合成表；
- **原点不变量（2026-09-07）**：生效表 `kMShape68.v` 原点 = 鼻尖 30（与 deploy
  face_model_468.npz 的 MP #1 原点设置一致），`t_hc` 即鼻尖在相机系位置。
  `apply_to_cpp` 写入新偏移时自动把基础表平移 -Δ30（Δ30 = 新旧偏移第 30 号
  元素之差）维持该不变量；手工改表时需自行保持；
- **鼻尖不作为可动点（2026-09-07）**：偏移块第 30 号元素不是形状旋钮——
  XY 定型与 Z 步进均冻结 [30]=0，鼻尖残差属于"脸部相对鼻尖"的原点放置差，
  由 PnP 平移 t 吸收或随脸部点修正一并解决；含非零 [30] 的历史块在下次
  `--apply` 时由 Δ30 重锚一次性规范化（基础表随之平移，此后 [30] 恒 0）；
- `solve_pnp.cpp` 属 `faceid_example` 静态链接部分，改表后必须重编并重推
  `faceid_example` 本身（`tools/make.sh`），只推 .so 无效。

## 2. 坐标系与单位约定

| 项 | 约定 |
|---|---|
| 坐标系 | F 头部系：X=被摄者左、Y=下、Z=后脑（负 z 朝脸前），右手系 |
| 模型原点 | 生效表 `kMShape68.v` 原点 = 鼻尖 30（2026-09-07 重锚，与 deploy face_model_468.npz 的 MP #1 一致）；`t_hc` 即鼻尖位置 |
| 模型单位 | 1 单位 = `mm_per_unit` mm，`mm_per_unit = kRealEyeOuterMm / 外眼距(36-45)`（外眼距取生效表；kRealEyeOuterMm 当前=104.1326，2026-09-10 由 pitch20 门控 10 轮无冻结版写回） |
| 头姿角 | (pitch, yaw, roll) 度，设备 F->C 约定，`R_hc = Rz(roll)·Ry(yaw)·Rx(pitch)`（外旋 X→Y→Z），低头为正 |
| 检测点 | 像素，iBUG68 序（pipnet68 输出序），来源为设备 `DUMP_LANDMARKS=1` dump 的 `LM i x y` 行 |
| 内参 | 设备标定内参 fx=1710.7017 / fy=1708.3478 / cx=799.5 / cy=649.5 |

## 3.1 总流程三模式（--mode）

`--dump` 帧流 + `--mode` 构成总流程的三种工作方式：

| 模式 | 行为 |
|---|---|
| `--mode 1`（none） | **不使用偏移**：仅基础表 kMeanShape68，逐帧 PnP 复解 + 重投影 RMS 评估 |
| `--mode 2`（current） | **使用当前偏移**：基础表 + 现有 FineTuneX/Y/Z，同口径评估（与模式 1 对比看偏移收益） |
| `--mode 3`（online） | **xy-fixed 两阶段在线标定**（当前标准）：正视启动帧 XY 一次定型 → 后续仅 Z/尺度微调，下述状态机 |

> **RMS 口径**：重投影 RMS 仅由**对比关键点**计算——即设备端 PnP 实际使用的
> `kLmk3dPairs` 对应点集 **27/28/29（鼻梁）、31/35（鼻翼）、36/45（外眼角）、39/42（内眼角）、48/54（外嘴角）、60/64（内嘴角）**
> （`CMP_IDX`，2026-09-10 起 13 点口径：鼻尖 30 移出对应点集——其仍是模型
> 原点、t_hc 语义不变，但残差由设备 PnP 的 t 吸收，8 点期"30 固定位姿残差
> 不可修正"问题随之消除）。PnP 解算对应点仍取轮廓外
> 17-67；分区均值等为诊断信息不参与判据。

### 3.1.1 状态机（xy-fixed 两阶段）

**阶段一：XY 一次定型（启动帧，仅一次）**

正视启动帧（`--frontal-startup`，位姿钉死 `--frontal-fixed-pose`，先验角
`--frontal-angles` 取 dump 设备 F->C 行——yaw 强制 0 会迫使镜像对称模型
吸收 ~1° 真实偏航、偏移放大约 3 倍）以固定位姿联合 LM 一次求解
(t, 对称参数化 XY)（`xy_fixed_calibrate`）：

- 镜像对 x 反对称 / y 同号、中线点 x=0 / y 独立、**眼睑 8 点由眼角偏移按
  弦长比例等比插值**、[30]=原点恒冻结；
- mm 固定为 基础尺度/基础表外眼距（消除外眼距→mm→重缩放简并谷）；
- 偏移正则 λ·‖off‖²（`--xy-lam-reg`，默认 1e-3）抑制单正视帧弱观测方向
  （下颌等）漂移；迭代上限 `--xy-iters`（默认 25）。

定型后 **X/Y/P 阶段全程跳过**——联合求解后设备口径自由解 pitch/yaw 与先验
差 <1°，伪 pitch 问题随定型一并消除。

**阶段二：逐帧 Z 深度/尺度微调**

1. **姿态绝对值门控**：|pitch| > `--pose-pitch-thr`（默认 **20°**）或
   |yaw| > `--pose-abs-thr`（默认 30°）的帧
   **不做任何偏移计算**（仅评估 RMS）。大角度帧检测点位本身
   不准（量化：8 点自拟合 RMS 4.6→8.6px 随偏航单调放大，最差点鼻尖中位
   17px/嘴角 11px+，位姿解算本身稳定——非 PnP 盆地问题）；大俯仰帧检测
   y 与深度耦合失真，pitch 门控收紧到 20°（2026-09-10）；
2. **尺度步进**（独立于姿态门控，豁免收敛冻结）：观测**完全自足**——只用
   当前帧关键点检测 + 当前模型（含已累积偏移与当前尺度）自解 PnP（17-67 点
   全口径 `solve_pose`，不用 dump 预计算的 W->dir/F->W 行——那些由拍摄时刻
   旧模型解出、不随偏移更新，是历次尺度漂移的根因），经 **C2W_R/C2W_B**
   （181 帧 (t_hc→t_hw) 对 Kabsch 拟合的相机系→车辆系刚体变换，残差
   0.025mm）得到车辆系头中心与头前向。正视门控：头前向与 yz 纵向铅垂面
   夹角 asin(|vx|) ≤ `--scale-dir-plane-thr`（水平直视车头、无侧向分量）
   且人脸不贴边（68 点包络距边 ≥ `--edge-margin`×宽/高）。步进公式：
   头中心车辆系 x = a·s + b_x（a=(C2W_R·t_hc).x/s 为尺度不变量，
   b_x=66.0mm 相机偏置不随尺度缩放）→ s* = (365−b_x)/a，delta =
   clip(s*−s, ±`--max-scale-step` 1mm)。
   **基础尺度 + 偏移口径**：尺度 = 基础 90mm（`--scale-init` 可覆盖，与初始
   标准模型同口径）+ 尺度偏移累积叠加；**观测每帧自解重算、不随偏移块步进
   重置**（重置仅保留在写回边界——`--apply` 后从 cpp 读回基础值重新起步；
   进程内重置会因 Z 每帧改写偏移块形成重置风暴、把尺度锁死 90-91mm，
   2026-09-09 已删除）。当前尺度即 solve_pnp.cpp 的 `kRealEyeOuterMm`，
   调整即时生效于后续所有解算/偏移/评估，保存时随偏移块写回；
3. **Z 深度步进**：头姿（pitch/yaw 复解值）相对上次 Z 更新变化 ≥
   `--pose-delta-thr`（默认 5°）时按当前检测-投影差异做深度雅可比微步并
   累加（边沿触发：拒绝后同一位姿不再重评）；单步限幅 `--max-step`
   （默认 0.3mm，**推荐 0.5mm**——10 轮内可完成收敛）；正视图锚点判据
   `--frontal-guard-tol`（默认 0.05px）：候选步进不得使正视图固定位姿
   RMS 恶化超容差（拒绝记 "Z 拒绝"）；
4. **收敛冻结（轮末判定）**：整轮 |Δdz| 的 L2 < `--z-conv-tol`（默认
   0.3mm）→ Z 停止更新，尺度豁免冻结继续走向 365mm 平衡值；
5. **保存**：近 `--stab-window`（默认 5）帧 13 点 RMS 均值 < `--rms-thr`
   （默认 5px）且标准差 < `--stab-std-thr`（默认 0.3px）时保存当前偏移块
   并结束；`--save-pose-check` 加验位姿一致性（设备口径 13 点自由复解
   pitch/yaw/roll 与先验差 ≤ `--save-pose-tol` 3° 才允许保存——偏移块与
   俯仰存在简并谷，防保存落到远离先验的伪 pitch 块污染视线链路 R_hc）；
   `--no-early-stop` 时判据达成仅记录不终止；帧流结束未达标仍会落盘最终
   累积值（头部标注"判据未达成"，评估确认后仍可写回——z05 即此情形）。

**验证结果**（10 轮、`--max-step 0.5`，mode3_10r_xyfixed_z05，2026-09-09
写回部署）：

- Z 轮间 |Δdz| L2 衰减比 ~×0.5/轮：17.7→…→0.33→**0.159mm < 0.3mm（R8 触发
  收敛冻结）**，R9/R10 Z 步进=0；
- 尺度 R5 起进入平衡带，终值 **104.91mm**；
- 位姿一致性 10/10 轮 ✓（pitch +0.4°/yaw +0.6°/roll +3.0° vs 先验 0/1/3.1）；
- 门控帧（|pitch|,|yaw|≤30°，n=122）8 点 RMS（当时口径）中位 **4.21px** /
  均值 6.75px（写回前现役 5.46/7.93px）；
- XY 定型逐位确定：0.3mm 与 0.5mm 步长两轮 round1 dx/dy 最大差异 = 0.00。

（0.3mm 步长版 mode3_10r_xyfixed：R10 末 ΔL2=0.38mm 未过阈、其余指标等价，
中位 4.22px。）

## 3.2 阶段总览与自由度分配（速查）

```
启动帧 XY 定型 →（逐帧）尺度 → 姿态门 → Z → 轮末收敛冻结判定 → 复解评估/保存判据
```

| 阶段 | 触发/门控 | 优化量 | 单步限幅 | 守门 |
|---|---|---|---|---|
| XY 定型 | 启动帧一次（正视固定位姿） | (t, 对称参数化 dx, dy) 联合 LM | —（一次解） | [30]=0、眼睑插值、正则 λ |
| 尺度 | 头前向与 yz 面夹角 asin(\|vx\|)≤阈值、人脸不贴边、a>0 | 外眼距尺度 = 基础 90mm + 尺度偏移（不随偏移块步进重置） | ±1.0mm | — |
| 姿态门 | —（前置过滤） | — | — | \|pitch\|>20° 或 \|yaw\|>30° 全跳过 |
| Z | 头姿变化 ≥5°（边沿触发） | 深度雅可比微步 dz | 0.3mm（推荐 0.5mm） | frontal_guard |
| 收敛冻结 | 轮末 \|Δdz\| L2 < 0.3mm | —（锁死 Z；尺度豁免继续步进） | — | — |

自由度分配总表（●=独立参数，⟂=由眼角等比插值放置，—=冻结/无参数）：

| 点组 | XY（定型 LM 参数化） | Z（步进） |
|---|---|---|
| 下颌 0-16 | ●（镜像对+中线对称参数） | —（轮廓） |
| 眉 17-26 | ● | ●（镜像对） |
| 鼻梁 27-29 | ●（27 为中线点，x=0） | ●（dz27） |
| 鼻尖 30 | 恒 0 | 恒 0 |
| 鼻翼 31-35 | ●（中线） | — |
| 眼角 36/39/42/45 | ●（镜像对绑定） | —（深度基准） |
| 眼睑 37/38/40/41/43/44/46/47 | ⟂（角点插值） | ⟂（恒 0） |
| 嘴 48-67 | ●（镜像对+中线） | ●（镜像对） |

结构性事实（设计依据）：

- **眼部自由度收敛到 4 个眼角点（2026-09-08）**：眼睑 8 点不取自身残差，
  其偏移恒等于 `off_睑 = (1−t)·off_外角 + t·off_内角`（t 为该睑点在基础表
  外角→内角弦上的投影比例，全程固定；XY 定型与 Z 步进后以同式维护不变量，
  冒烟验证残差 2.8e-17）。动机：眼角是锐利、可重复的特征点，眼睑检测抖动大
  （IR 暗光尤甚），逐点贴合会把噪声烙进模型；等比放置保持眼睑弯曲形状
  （垂直于弦的弧高由基础表锁定），只跟随角点位移场。眼区无 Z：眼角点是
  深度基准，所有 dz 为相对眼角的偏移，防深度漂移污染眼 patch 归一化；
- **鼻尖 30 恒为原点**：所有阶段增量结构性为 0（无"事后抹零"），写回
  Δ30 重锚只做等价转写（鼻尖动 δ ≡ 脸反向动 δ），鼻尖-脸相对几何仅由
  基础表决定；67 个非鼻尖点之间的相对形状在任何写回下都不受 Δ30 影响
  （全表统一平移，点间差不变）。

## 4. 核心算法

### 4.1 XY 一次定型（xy_fixed_calibrate）

正视固定位姿下的联合最小二乘：参数 = 平移 t(3) + 对称化 XY 偏移（镜像对
x 反对称/y 同号 + 中线点 x=0/y 独立；眼睑由角点插值不设参数，[30]≡0），
LM 迭代（阻尼相对 diag(H)，默认 25 轮）最小化
‖检测 − 投影(eff)‖² + λ·‖偏移(mm)‖²。要点：

- **mm 固定**（基础尺度/基础表外眼距），不随偏移迭代重标——外眼距→mm→
  重缩放存在简并谷，逐帧"残差→脸偏移累积 + t 重拟合"的朴素迭代会沿谷
  系统性漂移（80 次迭代 8 点 RMS 1.1→3.4px）；
- 偏移正则矩阵对参数线性（eff 对参数线性、t 不进偏移），弱观测方向
  （下颌等单正视帧）由 λ 抑制漂移；
- 右眼 yaw 先验取 dump 设备角（非强制 0，理由见 3.1.1）。

### 4.2 Z 深度步进（gn_z_step）

1. **位姿复解**：多起点迭代 PnP（仅用轮廓外点 17-67；单目下轮廓内点深度
   不可辨识，含轮廓会拖歪位姿）。有设备头姿角时作热启动，缺省纯网格
   （pitch −24°..+6° × yaw −8°/0°/+8°）；t 初值由检测外眼距反推
   （z0 = fx·90mm/外眼距px）。与设备协议一致（单帧 PnP 重解 = 可部署指标）；
2. **单帧微步**：在当前模型/位姿处线性化，深度雅可比
   ∂u/∂dz = fx·(R₀₂Z − x_c·R₂₂)/Z²，对称参数化（镜像对绑定一个参数
   dz 左=右、中线点单参数），岭正则最小二乘解微步。残差仅取 17-67 点；
3. **冻结约定**：眼区 36-47 与轮廓 0-16 的 dz 恒 0（眼角为深度基准，
   所有 dz 为相对眼角的偏移），眼区残差仍计入；
4. **限幅**：|dz| 超过 max-step（默认 0.3mm，推荐 0.5mm）整体缩放。

⚠️ 已知简并（重要经验）：

- 单人同姿态数据对 z 不可辨识：差分 z 与公共位姿（yaw/pitch/tz）存在简并谷，
  单帧/同姿态多帧的 dz 只是方向约束的微步。完整标定须**多姿态帧 + 逐轮迭代**，
  每轮后用单帧 PnP 重解（可部署指标）评估选优；
- 联合优化（位姿+z 同时调整）会沿简并谷过冲（位姿漂移），其内部 cost 不可信，
  评估必须用可部署指标。

## 5. 更新流程（标准命令）

```bash
# 1. 设备采集：启动正视 dump + 各姿态类别帧流（DUMP_LANDMARKS=1，含 LM 行与 F->C 行）

# 2. xy-fixed 两阶段 10 轮标定（先看数值，确认后加 --apply）
python3 tools/pfld68_convert/finetune_offsets.py --mode 3 \
    --startup-glob src/input_dump.txt \
    --round-robin 'fenxin_result/*' \
    --rounds 10 --no-early-stop \
    --frontal-startup --frontal-fixed-pose --frontal-angles 0.0 0.99 3.09 \
    --xy-fixed --max-step 0.5 --save-pose-check \
    --out-prefix mode3_10r_xyfixed [--apply]

# 3. 写回后重编并推送（faceid_example 静态链接，模型表编死在可执行文件里）
tools/make.sh   # 构建 libfacevision.so + faceid_example，推送到设备

# 4. 设备验证 + deploy 对拍（模型表变化会直接改变 PnP 头姿与视线归一化数值）
```

要点：

- `--frontal-angles` 取启动帧 dump 的设备 F->C 行角度（先验位姿）；
- `--no-early-stop` 用于观察全程（判据达成仅记录不终止）；正式标定可去掉；
- 先不带 `--apply` 跑完看对比（工具自动输出 模式3偏移 vs 现役块 逐轴差异
  + 两模型同帧流复评），确认后再加 `--apply` 写回（Δ30 重锚自动维护、
  kRealEyeOuterMm 同步更新）。

写回行为（`apply_to_cpp`，幂等）：只替换对应数组体（前后注释保留）、
同步尺度常量、自动平移基础表维持鼻尖原点不变量；表不存在时插入到合并
结构体之前并补上该轴累加项。

## 6. 注意事项

- ⚠️ 三块偏移表变化会直接改变 PnP 头姿与视线归一化数值，部署后需重新对拍 deploy；
- 嘴部 48-67 勿做逐点偏移（IR 暗光下 pipnet 嘴部抖动 ±5-10px，逐点贴合会把
  检测噪声烙进模型）——对称参数化 + 镜像绑定天然抑制；
- 基础表重生成（`gen_mean_shape68.py --write-c`）后，偏移块是叠加在其上的
  增量，语义随之改变，需复核或重标；
- fujiazuoyi 等目录名带尾空格，shell 通配/glob 已兼容，手写 case 模式需引号。
